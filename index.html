NVIDIA NeMo RL

★ 2.0k

An open-source framework for scalable LLM post-training and reinforcement learning.

  • I optimized log-probability and top-k distillation paths to remove unnecessary compute and communication.
  • I am adding multi-reward GDPO support so separate reward signals survive the asynchronous training pipeline.
  • I am also working on streamed SingleController PPO minibatches to reduce memory pressure without changing training behavior.

wayfind

A shared planning and memory layer for people and AI agents: one goal, with a view designed for each reader.

  • Plans backward from the goal and forward from the evidence already available.
  • Turns the same memory into compact agent briefings and a navigable map for people.
  • Works through a Claude Code plugin, an MCP server, and a fully offline map.
