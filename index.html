wayfind

A plan your AI agents can read and a memory they keep up to date: people and agents share one goal-oriented memory, each through its own view.

  • Searches from both ends: backward from the goal to what it needs, forward from what exists to what can be built.
  • Compiles one memory for each reader: token-budgeted briefings for agents, a map with one-click decisions for people.
  • Works with Claude Code as a plugin and with Codex; standard-library Python, an MCP server, and an offline map.
